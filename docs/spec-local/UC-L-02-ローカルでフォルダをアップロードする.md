# UC-L-02 ローカルでフォルダをアップロードする

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-L-02
- Name: ローカルでフォルダをアップロードする
- Primary actor: Script
- Preconditions: None
- Related: 画像と動画の拡張子は R-MEDIA-04。名前の形は R-MEDIA-01。撮影日時の決め方は R-MEDIA-03。ローカルアップロードの書き込みロックは R-LOCAL-01。本番のアップロードは [UC-04](../spec/UC-04-フォルダをアップロードする.md)。
- Postconditions (success):
  - 対象が 1 件以上あるとき、コンソールは「ローカルの photogallery-media へ N 件」を出す。上げた件ごとに「`uploaded 手元の名前 -> 付けた名前 (バイト数 bytes)`」を出す。付けた名前は本体の名前である。サムネイルを書いてから本体を置く。これらの行はフォルダの順とは限らない。ディスク上の画像と動画は残る。
  - 対象が 0 件のとき、「アップロード対象の画像・動画はフォルダ直下にありませんでした。」が出る。
  - スクリプトは確認を待たない。
- Postconditions (failure):
  - フォルダを渡さないとき、「使い方: pnpm upload:local <フォルダ>」が出て、スクリプトは失敗する。
  - 渡したパスがフォルダではないとき、「フォルダではありません: 」のあとにそのパスが出て、スクリプトは失敗する。
  - いつもの開発サーバーが動いていて、ストレージに書けないとき、「`pnpm dev` を止めてから実行して」が出て、スクリプトは失敗する。何も置かない。
  - 件数を出したあと、実行の途中で名前付けが失敗すると、画像も動画も上がらない。
  - 実行の途中で一部のアップロードが失敗すると、「`failed 手元の名前: 理由`」が出る。実行の終わりに「N 件失敗しました。」が出て、スクリプトは失敗する。失敗しなかった件は置いてある。

### Flow

1. スクリプトは「`pnpm upload:local <フォルダ>`」で始まる。先頭の `--` は飛ばす。
   - 1e. フォルダを渡していない。
     1. スクリプトは「使い方: pnpm upload:local <フォルダ>」を出して失敗する。
   - 1f. 渡したパスがフォルダではない。
     1. スクリプトは「フォルダではありません: 」のあとにそのパスを出して失敗する。
2. スクリプトは R-MEDIA-04 で対象を数える。
   - 2a. 対象が 0 件である。
     1. スクリプトは「アップロード対象の画像・動画はフォルダ直下にありませんでした。」を出す。
3. スクリプトは「ローカルの photogallery-media へ N 件」を出す。
4. スクリプトは R-MEDIA-03 と R-MEDIA-01 で、対象ごとの名前を決める。
   - 4e. 名前付けが失敗する。
     1. スクリプトは何も上げずに失敗する。
5. スクリプトはサムネイルを書いてから本体を書く。件ごとに「`uploaded 手元の名前 -> 付けた名前 (バイト数 bytes)`」を出す。付けた名前は本体の名前である。
   - 5e. いつもの開発サーバーが動いていて、ストレージに書けない。
     1. スクリプトは「`pnpm dev` を止めてから実行して」を出して失敗する。何も上げない。
   - 5f. 実行の途中で一部のアップロードが失敗する。
     1. スクリプトは「`failed 手元の名前: 理由`」を出し、残りの対象を続ける。
     2. 実行の終わりに、スクリプトは「N 件失敗しました。」を出して失敗する。
