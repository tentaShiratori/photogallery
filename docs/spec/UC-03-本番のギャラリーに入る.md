# UC-03 本番のギャラリーに入る

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-03
- 名前: 本番のギャラリーに入る
- 主アクター: ユーザー
- 事前条件: 本番のギャラリーで、開いてよい Google アカウントのメールアドレスが 1 件以上決まっている。
- 関連: 届いたあとの見出しの横のログイン表示は UC-01。
- 事後条件（成功）:
  - 許可されたメールアドレスのアカウントがギャラリーに届いている。
  - ログインしてから 24 時間たつと、そのログインは切れる。
  - 本番の公開先もプレビューも、同じ許可で守られている。
- 事後条件（失敗）: ギャラリーの画面は出ていない。Cloudflare Access の画面になっている。

### フロー

1. ユーザーが本番のギャラリーを開く。
2. ブラウザは Google へ直接進む。
3. 許可されたメールアドレスのアカウントである。
   - 3e. 許可されていない。
     1. ブラウザはギャラリーの画面を出さず、Cloudflare Access の画面を出す。
4. ブラウザは、そのアカウントをギャラリーに届ける。
5. ブラウザは、ログインしてから 24 時間でそのログインを切る。本番の公開先もプレビューも、同じ許可で守る。
