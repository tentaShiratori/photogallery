# ギャラリー

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-GAL-01

- ID: UC-GAL-01
- 前提: 画像または動画が 1 件以上置いてある。
- 操作: `/` を開く。
- 見えること:
  - タブと一番上の見出しは「フォトギャラリー」。検索結果に出さない指定が付く。
  - 開いた直後は「読み込み中です。」
  - 読み終わると「N 件」と出る。N はタイルの数。見出しの横のログイン表示は [ログイン表示](login.md)。
  - タイルは年の見出しの下に並ぶ。見出しは UC-GAL-03、順番は UC-GAL-04。
  - 各タイルの下に、名前の最後の部分が出る。画像のタイルは静止画、動画のタイルは映像で、その場では再生を始めない。
  - タイルの絵は枠に合わせて切れ、枠の外は見えない。
  - タイルの中身は `/api/media` の一覧と同じ名前、同じ年、同じ順で出る。見方は UC-GAL-06。
  - 画像と動画以外は、置いてあっても出ない。件数にも入らない。
- 例外: 一覧の応答が 2xx でないときは「一覧を取得できませんでした。」となり、タイルは出ない。

## UC-GAL-02

- ID: UC-GAL-02
- 前提: 画像も動画も置いていない。
- 操作: `/` を開く。
- 見えること: 「読み込み中です。」のあと、「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」と出る。タイルは無い。
- 例外: なし

## UC-GAL-03

- ID: UC-GAL-03
- 前提: 名前の形が違う画像や動画が置いてある。
- 操作: `/` を開く。
- 見えること:
  - 見出しは年の数字か「年不明」だけ。新しい年が上。「年不明」は常に最後。該当が 1 件も無い見出しは出ない。
  - 年は、名前の最後の部分だけから読む。
  - 最後の部分が `年4桁-月2桁-日2桁T時2桁-分2桁-秒2桁` の形で、その日時が実在し、末尾が画像か動画の小文字の拡張子であるとき、その年の見出しに入る。拡張子の直前に `-` と数字が付いていても、同じ日時として読む。例は `2024-08-02T12-00-00.jpg` と `2024-08-02T12-00-00-2.jpg`。どちらも 2024 年の同じ撮影日時。
  - この形に合わない画像と動画は「年不明」。撮影日時は空。例は `u-abc.png` と `folder/nested.jpg`。後者のタイルに出る呼び名は `nested.jpg`。
  - 拡張子が大文字の名前は、この形に合わない。画像や動画として並ぶときは「年不明」。
  - 実在しない日時の名前は「年不明」。
  - アップロード時刻は、年の見出しには使わない。同じ秒の順番と、「年不明」の順番に使う。UC-GAL-04。
- 例外: なし

## UC-GAL-04

- ID: UC-GAL-04
- 前提: 同じ見出しに画像または動画が 2 件以上ある。
- 操作: `/` を開く。
- 見えること:
  - 同じ年の中では、撮影日時の新しいものが上。
  - 撮影日時が同じ秒のときは、アップロード時刻の新しいものが上。アップロード時刻も同じときは、名前の文字順で早いものが上。例として、アップロード時刻が同じなら `2024-08-02T12-00-00-2.jpg` は `2024-08-02T12-00-00.jpg` より上。
  - 「年不明」の中では、アップロード時刻の新しいものが上。同じときは、名前の文字順で早いものが上。
- 例外: なし

## UC-GAL-05

- ID: UC-GAL-05
- 前提: 一覧に上限があり、置き場の一覧がその上限で止まっている。
- 操作: `/` を開く。
- 見えること: 取れた画像と動画が 1 件以上あるとき、件数のうしろに「（上限で打ち切っています）」が付く。タイルは取れた分だけ。例は「2 件（上限で打ち切っています）」。
- 例外: 画像と動画が 1 件も取れないときは、上限で止まっていても UC-GAL-02 の文言になる。打ち切りの文言は付かない。上限に達していないときも、打ち切りの文言は付かない。

## UC-GAL-06

- ID: UC-GAL-06
- 前提: なし。空でも、画像や動画があってもよい。
- 操作: `/api/media` を開く。
- 見えること:
  - JSON で、`truncated` と `groups` だけを持つ。`groups` の外に並びは無い。
  - `truncated` は、一覧を最後まで取れたとき false、上限で止めたとき true。
  - `groups` の各要素は `label`、`year`、`items`。年の見出しでは `label` がその年の数字、`year` がその年。`年不明` では `label` が「年不明」、`year` は null。
  - `items` の各要素は `key`（名前）、`kind`（`image` または `video`）、`size`（バイト数）、`uploaded`（アップロード時刻。`2026-10-18T09:00:00.000Z` の形）、`url`（`/media/` で始まる配信の場所）、`captured`（`year` `month` `day` `hour` `minute` `second`）。撮影日時が無いときは `captured` は null。
  - 画像と動画以外は含まれない。年、順番、有無は UC-GAL-03 と UC-GAL-04 と UC-GAL-02 と同じ。
  - 応答は保存しない。`Cache-Control` は `private, no-store`。
- 例外: なし
