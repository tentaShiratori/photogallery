# ギャラリー

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-GAL-01 ギャラリーを開く

- ID: UC-GAL-01
- 名前: ギャラリーを開く
- 主アクター: ユーザー
- 事前条件: なし
- 関連: 年は UC-GAL-03。順番は UC-GAL-04。上限は UC-GAL-05。一覧の形は UC-GAL-06。続きは UC-GAL-07。見出しの横は [ログイン表示](login.md)。
- 事後条件（成功）:
  - タブにタブの印が出ている。
  - メディアが 1 件以上あるとき、メディアのある最初の年のタイルが 60 件まで出ている。その年の見出しの横に「N 件」が出ている。N は、まだ出していないタイルも含めた、その年のメディアの数。タイルの絵はサムネイルで、呼び名は本体の名前である。
  - タイルが画面の下まで届かないときは、ユーザーがスクロールしなくても UC-GAL-07 の続きが出ている。届いているときは、その年より古い年の一覧をまだ取っていない。
  - 画像も動画も無いとき、「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」が出ている。
- 事後条件（失敗）: 「一覧を取得できませんでした。」が出ている。タイルは出ていない。

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、タブと見出しを「フォトギャラリー」にする。
3. ブラウザは、タブにタブの印を付ける。
4. ブラウザは、検索結果に出さない指定を付ける。
5. ブラウザは「読み込み中です。」を出す。
6. ブラウザは、UC-GAL-03 の順に、メディアのある最初の年まで 1 年ずつ一覧を取る。
   - 6a. どの年にも「年不明」にもメディアが無い。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」を出す。
   - 6e. 一覧の応答が 2xx でない。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「一覧を取得できませんでした。」を出す。
   - 6f. 通信が失敗する。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「一覧を取得できませんでした。」を出す。
   - 6g. 一覧の JSON が壊れている。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「一覧を取得できませんでした。」を出す。
7. ブラウザは「読み込み中です。」を消す。
8. ブラウザは、その年の見出しを「N 件」と一緒に出す。
9. ブラウザは、その年のメディアを、タイルとして 60 件まで出す。絵はサムネイル、呼び名は本体の名前。
   - 9a. タイルが画面の下まで届かない。
     1. ブラウザは、ユーザーがスクロールしなくても、UC-GAL-07 の続きを出す。

## UC-GAL-03 年を決める

- ID: UC-GAL-03
- 名前: 年を決める
- 主アクター: ユーザー
- 事前条件: 画像か動画が 1 件以上ある。
- 関連: 順番は UC-GAL-04。
- 事後条件（成功）:
  - 本体の名前が `年4桁-月2桁-日2桁T時2桁-分2桁-秒2桁` で始まり、その日時が実在し、末尾が画像か動画の拡張子である件は、その年である。拡張子の直前の `-数字` は同じ日時のまま。例は `2024-08-02T12-00-00.jpg` と `2024-08-02T12-00-00-2.jpg`。どちらも 2024 年。
  - 年の見出しは、先頭に 0 を付けない数字である。例は、`0007-01-01T00-00-00.jpg` の年の見出しで、「7」。
  - 本体の名前が `u-` と 16 進 12 桁で始まる件は「年不明」で、撮影日時は空。例は `u-abc123def456.png`。
  - どちらの形にも合わない件は出ない。例は `u-abc.png` と、実在しない日時の `2023-02-29T00-00-00.jpg`。
  - 新しい年が先で、「年不明」は最後である。メディアの無い年には見出しが無い。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、各メディアの本体の名前から年を読む。
   - 2a. 名前が `u-` と 16 進 12 桁で始まる。
     1. ブラウザは、その件を「年不明」にする。
     2. ブラウザは、その件の撮影日時を空にする。
     3. ブラウザは、「年不明」を年のあとにする。
     4. ブラウザは、「年不明」の見出しを、その最初のタイルと一緒に出す。
   - 2b. どちらの形にも合わない。
     1. ブラウザは、その件を一覧から外す。
3. ブラウザは、新しい年を先にする。
4. ブラウザは、年の見出しを、その年の最初のタイルと一緒に出す。

## UC-GAL-04 順番を決める

- ID: UC-GAL-04
- 名前: 順番を決める
- 主アクター: ユーザー
- 事前条件: 同じ年、または「年不明」に、画像か動画が 2 件以上ある。
- 事後条件（成功）:
  - 同じ年では、撮影日時の新しいものが先。同じ秒は、アップロード時刻の新しいものが先。それも同じときは、名前の文字順で早いものが先。
  - 「年不明」では、アップロード時刻の新しいものが先。同じときは、名前の文字順で早いものが先。
  - タイルを 60 件ずつ出しても、その年のメディアを全部並べた順のまま出る。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、同じ年の中で、撮影日時の新しいものを先にする。
3. ブラウザは、同じ秒の中で、アップロード時刻の新しいものを先にする。
   - 3a. アップロード時刻も同じ。
     1. ブラウザは、名前の文字順で早いものを先にする。例として、`2024-08-02T12-00-00-2.jpg` は `2024-08-02T12-00-00.jpg` より先になる。
4. ブラウザは、「年不明」の中で、アップロード時刻の新しいものを先にする。同じときは、名前の文字順で早いものを先にする。

## UC-GAL-05 一覧を上限で止める

- ID: UC-GAL-05
- 名前: 一覧を上限で止める
- 主アクター: ユーザー
- 事前条件: ある年、または「年不明」の本体とサムネイルが、合わせて 20,000 オブジェクトより多くある。
- 関連: 見出しの横の件数は UC-GAL-01 と UC-GAL-07。
- 事後条件（成功）:
  - 見えたメディアが 1 件以上あるとき、その年の見出しの横で、件数のうしろに「（上限で打ち切っています）」が付いている。例は「10000 件（上限で打ち切っています）」。タイルは見えた分だけ出る。
  - 見えたメディアが 0 件のとき、その年の見出しは無い。
- 事後条件（失敗）: なし

### フロー

1. ユーザーが、その年の一覧を取るところまでギャラリーを見る。
2. ブラウザは、その年の本体とサムネイルを、同じ数ずつ交互に、合わせて 20,000 オブジェクトまで見る。
3. ブラウザは、20,000 オブジェクトを見たあとにも続きがあるので、その年の一覧を止める。
   - 3a. 見えたメディアが 0 件である。
     1. ブラウザは、その年を飛ばして次の年の一覧を取る。
4. ブラウザは、その年の件数のうしろに「（上限で打ち切っています）」を付ける。

## UC-GAL-06 一覧を渡す

- ID: UC-GAL-06
- 名前: 一覧を渡す
- 主アクター: ユーザー
- 事前条件: なし
- 関連: 年は UC-GAL-03。順番は UC-GAL-04。上限は UC-GAL-05。
- 事後条件（成功）:
  - JSON は `group` と `next` を持つ。1 回の応答で本体とサムネイルを見るのは、1 年分だけ。
  - `/api/media` は一番新しい年の分。`/api/media?after=年` は、その年より古い年のうち一番新しい年の分。どちらも、その年が無ければ「年不明」の分。
  - `group` は `label`、`truncated`、`items` を持つ。年では `label` がその年の数字、「年不明」では「年不明」。`truncated` は、UC-GAL-05 の上限で止めたとき true。`items` は UC-GAL-04 の順で 1 件以上あり、その数が見出しの横の件数になる。
  - その分にメディアが無いとき、`group` は null。
  - `items` の各要素は `bodyKey`（本体の名前）、`kind`（`image` または `video`）、`bodyUrl`（本体の配信）、`thumbUrl`（サムネイルの配信）、`caption`（本体の名前）。
  - `next` は続きの場所で、年の分では `/api/media?after=その年`、「年不明」の分では null。
  - `Cache-Control` は `private, no-store`。
- 事後条件（失敗）: 状態は 400 か 500。

### フロー

1. ユーザーが `/api/media` を開く。
   - 1a. ユーザーが `/api/media?after=年` を開く。
     1. ブラウザは、その年より古い年の分の JSON を受け取る。`Cache-Control` は `private, no-store`。
   - 1e. `after` が、1 から 9999 の先頭に 0 の無い数字でない。
     1. ブラウザは、状態 400 を受け取る。
   - 1f. 年を探すのに、名前を 1 回 1,000 件で 20 回見ても、まだ数字で始まる名前が続く。
     1. ブラウザは、状態 500 を受け取る。
2. ブラウザは、一番新しい年の分の JSON を受け取る。`Cache-Control` は `private, no-store`。

## UC-GAL-07 続きを出す

- ID: UC-GAL-07
- 名前: 続きを出す
- 主アクター: ユーザー
- 事前条件: ブラウザにタイルが 1 件以上出ている。
- 関連: 年は UC-GAL-03。順番は UC-GAL-04。上限は UC-GAL-05。一覧の形は UC-GAL-06。
- 事後条件（成功）:
  - 続きがあるとき、タイルが 60 件まで増えている。並びは UC-GAL-04 のとおり。
  - 新しい年のタイルが出たとき、その年の見出しの横に「N 件」が出ている。N は、まだ出していないタイルも含めた、その年のメディアの数。
  - 増えたタイルが画面の下まで届かないときは、ユーザーがスクロールしなくても、届くか全部出し終えるまで続けて出ている。
  - 全部出し終えていたときは、タイルも文言も増えていない。
- 事後条件（失敗）: 出ていたタイルは残っている。「続きを取得できませんでした。」と「もう一度」が出ている。

### フロー

1. ユーザーが画面の下までスクロールする。
   - 1a. 今の年に、まだ出していないタイルがある。
     1. ブラウザは、その年のタイルを、続きから 60 件まで出す。
   - 1b. 全部出し終えている。
     1. ブラウザは、一覧を取らない。
2. ブラウザは、UC-GAL-03 の順に、メディアのある次の年まで 1 年ずつ一覧を取る。
   - 2a. 残りの年にも「年不明」にもメディアが無い。
     1. ブラウザは、一覧を取るのをやめる。
   - 2e. 一覧の応答が 2xx でない、通信が失敗する、または一覧の JSON が壊れている。
     1. ブラウザは「続きを取得できませんでした。」と「もう一度」を出す。
     2. ユーザーが「もう一度」を選ぶ。
     3. ブラウザは「続きを取得できませんでした。」と「もう一度」を消す。
     4. ブラウザは、失敗した年から、メディアのある次の年まで 1 年ずつ一覧を取り直す。
     5. ブラウザは、その年の見出しを「N 件」と一緒に出す。
     6. ブラウザは、その年のタイルを 60 件まで出す。
3. ブラウザは、その年の見出しを「N 件」と一緒に出す。
4. ブラウザは、その年のタイルを 60 件まで出す。
