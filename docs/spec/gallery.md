# ギャラリー

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-GAL-01 ギャラリーを開く

- ID: UC-GAL-01
- 名前: ギャラリーを開く
- 主アクター: ユーザー
- 事前条件: なし
- 関連: 年は UC-GAL-03。順番は UC-GAL-04。上限は UC-GAL-05。見出しの横は [ログイン表示](login.md)。一覧の形は UC-GAL-06。
- 事後条件（成功）:
  - 本体とサムネイルが揃った画像か動画が 1 件以上あるとき、「N 件」が出ている。N はタイルの数。タイルの絵はサムネイルで、呼び名は本体の名前である。
  - 画像も動画も無いとき、「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」が出ている。
- 事後条件（失敗）: 「一覧を取得できませんでした。」が出ている。

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、タブと見出しを「フォトギャラリー」にする。
3. ブラウザは、検索結果に出さない指定を付ける。
4. ブラウザは「読み込み中です。」を出す。
5. ブラウザは一覧を取り終える。
   - 5a. 画像も動画も無い。
     1. ブラウザは「読み込み中です。」を消し、「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」を出す。
     2. 「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」が出ている。
   - 5e. 一覧の応答が 2xx でない。
     1. ブラウザは「読み込み中です。」を消し、「一覧を取得できませんでした。」を出す。
     2. 「一覧を取得できませんでした。」が出ている。
6. ブラウザは「読み込み中です。」を消し、「N 件」を出す。N はタイルの数。
7. ブラウザは、本体とサムネイルが揃った件をタイルとして出す。絵はサムネイル、呼び名は本体の名前。
8. 「N 件」が出ている。N はタイルの数。タイルの絵はサムネイルで、呼び名は本体の名前である。

## UC-GAL-03 年を決める

- ID: UC-GAL-03
- 名前: 年を決める
- 主アクター: ユーザー
- 事前条件: 画像か動画が 1 件以上ある。
- 関連: 順番は UC-GAL-04。
- 事後条件（成功）:
  - 本体の名前が `年4桁-月2桁-日2桁T時2桁-分2桁-秒2桁` で始まり、その日時が実在し、末尾が画像か動画の拡張子である件は、その年である。拡張子の直前の `-数字` は同じ日時のまま。例は `2024-08-02T12-00-00.jpg` と `2024-08-02T12-00-00-2.jpg`。どちらも 2024 年。
  - この形に合わない件は「年不明」で、撮影日時は空。例は `u-abc.png` と、実在しない日時。
  - 新しい年が先で、「年不明」は最後である。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、各メディアの本体の名前を読む。
3. ブラウザは、形が合う件をその年にする。
   - 3a. 形が合わない。
     1. ブラウザは、その件を「年不明」にし、撮影日時を空にする。
     2. ブラウザは、新しい年を先にし、「年不明」を最後にする。
     3. 「年不明」で、撮影日時は空である。新しい年が先で、「年不明」は最後である。
4. ブラウザは、新しい年を先にし、「年不明」を最後にする。
5. 形が合う件はその年である。新しい年が先で、「年不明」は最後である。

## UC-GAL-04 順番を決める

- ID: UC-GAL-04
- 名前: 順番を決める
- 主アクター: ユーザー
- 事前条件: 同じ年、または「年不明」に、画像か動画が 2 件以上ある。
- 事後条件（成功）:
  - 同じ年では、撮影日時の新しいものが先。同じ秒は、アップロード時刻の新しいものが先。それも同じときは、名前の文字順で早いものが先。
  - 「年不明」では、アップロード時刻の新しいものが先。同じときは、名前の文字順で早いものが先。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、同じ年の中で、撮影日時の新しいものを先にする。
3. ブラウザは、同じ秒の中で、アップロード時刻の新しいものを先にする。
   - 3a. アップロード時刻も同じ。
     1. ブラウザは、名前の文字順で早いものを先にする。例として、`2024-08-02T12-00-00-2.jpg` は `2024-08-02T12-00-00.jpg` より先になる。
     2. 名前の文字順で早いものが先である。
4. ブラウザは、「年不明」の中で、アップロード時刻の新しいものを先にする。同じときは、名前の文字順で早いものを先にする。
5. 同じ年では、撮影日時の新しいものが先。同じ秒はアップロード時刻の新しいものが先。それも同じときは名前の文字順で早いものが先。「年不明」では、アップロード時刻の新しいものが先。同じときは名前の文字順で早いものが先。

## UC-GAL-05 一覧を上限で止める

- ID: UC-GAL-05
- 名前: 一覧を上限で止める
- 主アクター: ユーザー
- 事前条件: 置き場に、1 回 1,000 件で 20 回見るより多くのオブジェクトがある。
- 関連: 0 件の文言は UC-GAL-01。
- 事後条件（成功）:
  - 画像と動画が 1 件以上見えたとき、件数のうしろに「（上限で打ち切っています）」が付いている。例は「2 件（上限で打ち切っています）」。タイルは見えた分だけ出ている。
  - 見えた画像と動画が 0 件のとき、UC-GAL-01 の 0 件の文言が出ている。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、置き場のオブジェクトを 1 回に 1,000 件まで、最大 20 回見る。画像と動画以外も、この 1,000 件に入る。
3. ブラウザは、20 回目のあとにも続きがあるので、一覧を止める。
   - 3a. 見えた画像と動画が 0 件である。
     1. ブラウザは、UC-GAL-01 の 0 件の文言を出す。
     2. UC-GAL-01 の 0 件の文言が出ている。
4. ブラウザは、件数のうしろに「（上限で打ち切っています）」を付ける。
5. 件数のうしろに「（上限で打ち切っています）」が付いている。タイルは見えた分だけ出ている。

## UC-GAL-06 一覧を渡す

- ID: UC-GAL-06
- 名前: 一覧を渡す
- 主アクター: ユーザー
- 事前条件: なし
- 関連: 年は UC-GAL-03。順番は UC-GAL-04。0 件は UC-GAL-01。上限は UC-GAL-05。
- 事後条件（成功）:
  - JSON は `truncated` と `groups` を持つ。
  - `truncated` は、一覧を最後まで取れたとき false、UC-GAL-05 の上限で止めたとき true。
  - `groups` の各要素は `label`、`year`、`items`。年では `label` がその年の数字、`year` がその年。「年不明」では `label` が「年不明」、`year` は null。
  - `items` の各要素は `bodyKey`（本体の名前）、`kind`（`image` または `video`）、`bodyUrl`（本体の配信）、`thumbUrl`（サムネイルの配信）、`caption`（本体の名前）。
  - `Cache-Control` は `private, no-store`。
- 事後条件（失敗）: なし

### フロー

1. ユーザーが `/api/media` を開く。
2. ブラウザは、`truncated` と `groups` を持つ JSON を受け取る。`Cache-Control` は `private, no-store`。
3. `truncated` は、最後まで取れたとき false、UC-GAL-05 の上限で止めたとき true。`groups` は `label`、`year`、`items` を持つ。`items` は `bodyKey`、`kind`、`bodyUrl`、`thumbUrl`、`caption` を持つ。
