# アップロード

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-UPLOAD-01

- ID: UC-UPLOAD-01
- 前提: 上げ先に書くための設定が `.env` にある。指定するパスはフォルダである。
- 操作: `pnpm upload -- <フォルダ>` を実行する。
- 見えること:
  - まず対象の件数と、上げ先のバケット名が出る。形式は「N 件を バケット名 へアップロードします。」
  - 1 件上がるごとに `uploaded 手元の名前 -> 付けた名前 (バイト数 bytes)` と出る。この行の並びは、フォルダの並びどおりとは限らない。
  - 付けた名前は UC-UPLOAD-03。その名前でギャラリーと配信から見える。
  - 手元のファイルは消えない。
- 例外:
  - フォルダを渡さないと失敗する。文言は「使い方: pnpm upload -- <フォルダ>」。
  - 指定したパスがフォルダでなければ失敗する。文言は「フォルダではありません: 」のあとにそのパス。
  - 必要な設定が無いと失敗する。未設定の項目名のあとに「が未設定です。.env.example を見て .env を作ってください。」
  - 対象が 0 件のときは「アップロード対象の画像・動画はフォルダ直下にありませんでした。」と出て、失敗にはしない。
  - 件数を出したあと、名前を決めている途中で失敗したときは、どのファイルも上がらず、失敗する。
  - 上げている途中で一部が失敗したときは、`failed 手元の名前: 理由` と出て、終わったあと「N 件失敗しました。」で失敗する。失敗しなかったファイルは置かれる。失敗のあとでも、残りのファイルは続ける。

## UC-UPLOAD-02

- ID: UC-UPLOAD-02
- 前提: フォルダの直下にファイルとサブフォルダがある。
- 操作: UC-UPLOAD-01 を実行する。
- 見えること:
  - 直下のファイルだけが対象。サブフォルダの中は見ない。フォルダ自体も対象外。
  - 対象の拡張子は、最後の拡張子が jpg、jpeg、png、gif、webp、avif、heic、heif、mp4、mov、webm、m4v のもの。大文字でも小文字でも対象。
  - `.` で始まる名前、拡張子が無い名前、上以外の拡張子は対象外。例として `archive.tar.gz` は対象外。
  - HEIC と HEIF も上がる。画面での見え方は UC-MEDIA-06。
- 例外: なし

## UC-UPLOAD-03

- ID: UC-UPLOAD-03
- 前提: UC-UPLOAD-02 の対象が 1 件以上ある。
- 操作: UC-UPLOAD-01 を実行する。
- 見えること:
  - 撮影日時が決まったファイルの名前は `YYYY-MM-DDTHH-mm-ss.拡張子`。時・分・秒の区切りは `-`。拡張子は小文字。例は手元の `IMG_0001.JPG` が `2024-08-02T12-00-00.jpg`。
  - 撮影日時が決まらないファイルの名前は `u-` に、中身から決まる 12 文字の小文字の 16 進、小文字の拡張子。中身が同じなら、この 12 文字は同じ。手元の名前は残らない。
  - 同じ実行の中では、フォルダを読んだ順に名前を決める。その時点で同じ名前がまだ無ければ、接尾なしの名前になる。既にあれば、拡張子の直前へ `-2` から番号を付ける。空いている最初の番号を使う。例は `2024-08-02T12-00-00-2.jpg`、次は `2024-08-02T12-00-00-3.jpg`。`u-` の名前も同じ規則で、例は `u-abc123def456-2.png`。
  - 別の実行では、置き場に既にある名前を見て番号を付けない。既にある同じ名前へ上げると、中身を置き換える。
  - ギャラリーのタイルには、この名前の最後の部分が出る。年の見出しは UC-GAL-03。
- 例外: なし

## UC-UPLOAD-04

- ID: UC-UPLOAD-04
- 前提: UC-UPLOAD-02 の対象がある。
- 操作: UC-UPLOAD-01 を実行する。撮影日時は、この実行のときに決める。
- 見えること:
  - ファイルの中から日時が取れたときは、それを撮影日時にする。更新日時が新しくても、中の日時を使う。
  - JPEG、PNG、WebP は、中に書かれた撮影日時を、書かれた数値のまま使う。形は `年:月:日 時:分:秒`。JPEG は撮影日時の項目があるときそれを使う。更新の項目しか無いときは、中からは撮影日時が決まらない。
  - AVIF、HEIC、HEIF は、撮影日時の場所がファイル先頭からの位置で指されているとき、書かれた数値のまま使う。形は JPEG と同じ。それ以外の指し方では、中からは撮影日時が決まらない。
  - MP4、MOV、M4V は、中の作成日時を協定世界時の暦にして撮影日時にする。作成日時が未設定のときは決まらない。変更日時が別に書いてあっても使わない。
  - GIF と WebM は、ファイルの中を見ない。
  - 中から日時が得られないとき、または読もうとして失敗したときは、更新日時を見る。実行した時点より 7 日より古い更新日時だけを、実行した機械の現地の暦で撮影日時にする。秒未満は捨てる。7 日ちょうど、およびそれより新しい更新日時では、撮影日時は決まらない。
  - 暦として成り立たない値では、撮影日時は決まらない。
  - ここまでで決まらないときの名前は、UC-UPLOAD-03 の `u-` から始まる形。
- 例外: なし
