# UC-02 ギャラリーのメディアを拡大する

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-02
- 名前: ギャラリーのメディアを拡大する
- 主アクター: ユーザー
- 事前条件: ギャラリーにサムネイルが 1 件以上出ている。
- 関連: R-GAL-04 は本体の配信。R-GAL-06 は HEIC と HEIF。
- 事後条件（成功）:
  - 拡大表示に本体が出ている。本体の名前が出ている。「閉じる」が出ている。
  - 選んだメディアが動画のとき、再生を始める指定と、再生を操作できる指定が付いている。
  - 「閉じる」を選んだあと、拡大表示は出ていない。タイルは残っている。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがサムネイルを選ぶ。
2. ブラウザは拡大表示に本体を出す。
   - 2a. 選んだメディアが動画である。
     1. ブラウザは再生を始める指定を付ける。
     2. ブラウザは再生を操作できる指定を付ける。
3. ブラウザは本体の名前を出す。
4. ブラウザは「閉じる」を出す。
   - 4a. ユーザーが「閉じる」を選ぶ。
     1. ブラウザは拡大表示を消す。
