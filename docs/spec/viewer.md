# 拡大表示

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-VIEW-01

- ID: UC-VIEW-01
- 前提: ギャラリーに画像のタイルがある。
- 操作: そのタイルを選ぶ。
- 見えること:
  - 拡大表示が開く。うしろが暗くなり、閉じるまでタイルは選べない。
  - 大きい静止画が出る。タイルのように枠で切れず、画面に収まる大きさで全体が見える。
  - 静止画の下に、タイルと同じ呼び名が出る。静止画の代替の文言もその呼び名。
  - 中身は、その画像の配信の URL から出る。
  - 「閉じる」が出る。
- 例外: なし

## UC-VIEW-02

- ID: UC-VIEW-02
- 前提: ギャラリーに動画のタイルがある。
- 操作: そのタイルを選ぶ。
- 見えること:
  - 拡大表示が開く。うしろが暗くなり、閉じるまでタイルは選べない。
  - 大きい映像が出る。枠で切れず、画面に収まる大きさで全体が見える。
  - 再生、シーク、音量の操作が付く。開くと再生を始める指定が付く。音はミュートしない。
  - 映像の下に、タイルと同じ呼び名が出る。
  - 中身は、その動画の配信の URL から出る。シークは配信の範囲取得になる。UC-MEDIA-03。
  - 「閉じる」が出る。
- 例外: なし

## UC-VIEW-03

- ID: UC-VIEW-03
- 前提: 拡大表示が開いている。
- 操作: 「閉じる」を選ぶ。
- 見えること: 拡大表示が閉じる。ギャラリーのタイルは、開く前と同じ呼び名で残っている。
- 例外: なし
