# UC-01 ギャラリーを見る

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-01
- 名前: ギャラリーを見る
- 主アクター: ユーザー
- 事前条件: なし
- 関連: R-MEDIA-02 は本体の名前から年を決める。R-GAL-01 は年とタイルの並び順。R-GAL-02 は一覧の上限。R-GAL-03 は一覧 API の形。
- 事後条件（成功）:
  - タブにタブの印が出ている。
  - ログインのメールが無いとき、見出しの横は「ローカルプレビュー」である。
  - メールがあるとき、見出しの横はそのメールアドレスである。`<`、`>`、`&`、`'`、`"` は文字のままである。
  - メディアが 1 件以上あるとき、メディアのある最初の年のタイルが 60 件まで出ている。その年の見出しの横に「N 件」が出ている。N は、まだ出していないタイルも含めた、その年のメディアの数。タイルの絵はサムネイルで、呼び名は本体の名前である。
  - タイルが画面の下まで届かないときは、ユーザーがスクロールしなくても続きのタイルが出ている。届いているときは、その年より古い年の一覧をまだ取っていない。
  - 続きを出したあと、続きがあるとき、タイルが 60 件まで増えている。並びは R-GAL-01 のとおり。
  - 新しい年のタイルが出たとき、その年の見出しの横に「N 件」が出ている。N は、まだ出していないタイルも含めた、その年のメディアの数。
  - 増えたタイルが画面の下まで届かないときは、ユーザーがスクロールしなくても、届くか全部出し終えるまで続けて出ている。
  - 全部出し終えていたときは、タイルも文言も増えていない。
  - 画像も動画も無いとき、「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」が出ている。
- 事後条件（失敗）:
  - 初回の一覧が取れないとき、「一覧を取得できませんでした。」が出ている。タイルは出ていない。
  - 続きの一覧が取れないとき、出ていたタイルは残っている。「続きを取得できませんでした。」と「もう一度」が出ている。

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、タブと見出しを「フォトギャラリー」にする。
3. ブラウザは、見出しの横にログイン表示を出す。
   - 3a. ログインのメールが無い。
     1. ブラウザは「ローカルプレビュー」を出す。
   - 3b. メールがある。
     1. ブラウザはそのメールアドレスを出す。
     2. ブラウザは、`<`、`>`、`&`、`'`、`"` を文字として出す。
4. ブラウザは、タブにタブの印を付ける。
5. ブラウザは、検索結果に出さない指定を付ける。
6. ブラウザは「読み込み中です。」を出す。
7. ブラウザは、R-GAL-01 の順に、メディアのある最初の年まで 1 年ずつ、R-GAL-03 の形で一覧を取る。
   - 7a. どの年にも「年不明」にもメディアが無い。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」を出す。
   - 7e. 一覧の応答が 2xx でない。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「一覧を取得できませんでした。」を出す。
   - 7f. 通信が失敗する。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「一覧を取得できませんでした。」を出す。
   - 7g. 一覧の JSON が壊れている。
     1. ブラウザは「読み込み中です。」を消す。
     2. ブラウザは「一覧を取得できませんでした。」を出す。
8. ブラウザは「読み込み中です。」を消す。
9. ブラウザは、その年の見出しを「N 件」と一緒に出す。
10. ブラウザは、その年のメディアを、R-GAL-01 の順でタイルとして 60 件まで出す。絵はサムネイル、呼び名は本体の名前。
    - 10a. タイルが画面の下まで届かない。
      1. ブラウザは、ユーザーがスクロールしなくても、続きを出す。
11. ユーザーが画面の下までスクロールする。
    - 11a. 今の年に、まだ出していないタイルがある。
      1. ブラウザは、その年のタイルを、続きから 60 件まで出す。
    - 11b. 全部出し終えている。
      1. ブラウザは、一覧を取らない。
12. ブラウザは、R-GAL-01 の順に、メディアのある次の年まで 1 年ずつ、R-GAL-03 の形で一覧を取る。
    - 12a. 残りの年にも「年不明」にもメディアが無い。
      1. ブラウザは、一覧を取るのをやめる。
    - 12e. 一覧の応答が 2xx でない、通信が失敗する、または一覧の JSON が壊れている。
      1. ブラウザは「続きを取得できませんでした。」と「もう一度」を出す。
      2. ユーザーが「もう一度」を選ぶ。
      3. ブラウザは「続きを取得できませんでした。」と「もう一度」を消す。
      4. ブラウザは、失敗した年から、メディアのある次の年まで 1 年ずつ一覧を取り直す。
      5. ブラウザは、その年の見出しを「N 件」と一緒に出す。
      6. ブラウザは、その年のタイルを 60 件まで出す。
13. ブラウザは、その年の見出しを「N 件」と一緒に出す。
14. ブラウザは、その年のタイルを 60 件まで出す。
