# UC-03 ギャラリーに入る

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-03
- Name: ギャラリーに入る
- Primary actor: User
- Preconditions: 許可した Google アカウントのメールアドレスがギャラリーに 1 件以上設定してある。
- Related: 本番の入場は R-ACCESS-01。到着後のログイン表示は UC-01。
- Postconditions (success):
  - 許可したメールアドレスのアカウントがギャラリーに着いている。
- Postconditions (failure): ギャラリーの画面は出ない。Cloudflare Access の画面が出る。

### Flow

1. 利用者がギャラリーを開く。
2. ブラウザは Google へ進む。
3. 利用者は許可したメールアドレスのアカウントでサインインする。
   - 3e. アカウントが許可されていない。
     1. ブラウザは Cloudflare Access の画面を出す。
4. ブラウザはそのアカウントをギャラリーに着ける。
