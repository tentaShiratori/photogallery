# 書き方

用語は [GLOSSARY.md](../../GLOSSARY.md)。挙動の正は領域のファイルにある。このファイルは形の見本である。

見ている人は、ギャラリー、拡大表示、ログイン表示、配信を使う人。上げる人は、手元のフォルダからアップロードする人。

今ある UC は、ID、前提、操作、見えること、例外の 5 項目で書いてある。UC を直すときは、直した UC だけ下の形に揃える。同じファイルの他の UC は、その PR で触らなければ 5 項目のままでよい。

## 必須の項目

| 項目             | 書くこと                                                                   |
| ---------------- | -------------------------------------------------------------------------- |
| ID               | `UC-領域-番号`。見出しと同じ                                               |
| 名前             | 動詞で終わる目的。例は「ギャラリーを開く」                                 |
| 主アクター       | 見ている人、または上げる人。1 UC に 1 人                                   |
| 事前条件         | 始まるときに既に成り立っていること。無ければ「なし」                       |
| 事後条件（成功） | 目的が達せられたときの、画面かコンソール                                   |
| 事後条件（失敗） | 目的が達せられなかったときの、画面かコンソール。失敗の道が無ければ「なし」 |
| 基本フロー       | 成功するときの手順。1 から番号を付ける                                     |
| 代替フロー       | 目的は達する、別の道。無ければ「なし」                                     |
| 例外フロー       | 目的は達しない道。無ければ「なし」                                         |

1 つの UC は 1 つの目的にする。名前に「管理する」「処理する」は使わない。新しい UC は、その領域のファイルに足す。

任意で足すのは、空でないときだけ。

- トリガー。基本フローの 1 が開始そのものでないとき
- 関連。詳細を別の UC に渡すとき
- 未決。まだ決まっていないことがあるとき

## 複写用

```markdown
## UC-GAL-01 ギャラリーを開く

- ID: UC-GAL-01
- 名前: ギャラリーを開く
- 主アクター: 見ている人
- 事前条件: なし
- 事後条件（成功）:
- 事後条件（失敗）:

### 基本フロー

1.

### 代替フロー

なし

### 例外フロー

なし
```

## 手順の書き方

1 行は、主語 1 つと動作 1 つ。主語は主アクターか、ギャラリー、アップロード、拡大表示、ログイン表示、配信。

分岐は基本フローに書かない。目的が達せられる別の道は代替フロー、達せられない道は例外フロー。事前条件に書いてあることは、フローで調べ直さない。ギャラリーやアップロードが調べて道を分けることは、代替フローか例外フローに書く。

代替フローは、分かれた手順の番号に `a`、`b` を付ける。手順 3 から分かれる成功の道は `3a`。例外フローは同じ番号に `e` を付ける。入れ子は `3e-1`。どちらも最後の行に、戻る手順の番号か、そこで終わることを書く。

「確認する」「処理する」「適切に」は使わない。何が起きて、画面かコンソールのどこに何が出るかまで書く。

画面とコンソールに出る文言は「」で囲み、今出ている文字列のまま書く。画面の呼び名は用語集の語を使う。配置、色、余白は書かない。実装、ファイル名、なぜそうするかは書かない。

## 記入例

見本である。開いたあとの件数、空のとき、一覧が失敗したときの文言は、[gallery.md](gallery.md) の UC-GAL-01 と UC-GAL-02 が正。年、順番、タイルの中身は gallery.md の他の UC が正。

```markdown
## UC-GAL-01 ギャラリーを開く

- ID: UC-GAL-01
- 名前: ギャラリーを開く
- 主アクター: 見ている人
- 事前条件: なし
- 事後条件（成功）: 「N 件」とタイルが出ている。件数が 0 のときは「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」が出て、タイルは無い。
- 事後条件（失敗）: 「一覧を取得できませんでした。」が出て、タイルは無い。
- 関連: 年の見出しは UC-GAL-03。順番は UC-GAL-04。見出しの横はログイン表示。

### 基本フロー

1. 見ている人がギャラリーを開く。
2. ギャラリーは「読み込み中です。」を出す。
3. ギャラリーは一覧を取り終える。
4. ギャラリーは「N 件」とタイルを出す。N はタイルの数。成功の事後条件で終わる。

### 代替フロー

3a. 画像も動画も無い。
3a-1. ギャラリーは「まだ画像も動画もありません。アップロードスクリプトで R2 に置いてください。」を出す。タイルは出さない。
3a-2. 成功の事後条件で終わる。

### 例外フロー

3e. 一覧の応答が 2xx でない。
3e-1. ギャラリーは「一覧を取得できませんでした。」を出す。タイルは出さない。
3e-2. 失敗の事後条件で終わる。
```
