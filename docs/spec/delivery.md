# 配信

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-MEDIA-01 中身を渡す

- ID: UC-MEDIA-01
- 名前: 中身を渡す
- 主アクター: ユーザー
- 事前条件: その名前の画像か動画が置いてある。
- 関連: 開けない形は UC-MEDIA-04。範囲は UC-MEDIA-03。
- 事後条件（成功）:
  - 状態は 200。本文はその画像か動画の中身。
  - `Content-Type` は、置いたときに付いていればそれ。無ければ拡張子で決まる。jpg と jpeg は `image/jpeg`、png は `image/png`、gif は `image/gif`、webp は `image/webp`、avif は `image/avif`、heic は `image/heic`、heif は `image/heif`、mp4 は `video/mp4`、mov は `video/quicktime`、webm は `video/webm`、m4v は `video/x-m4v`。
  - `Accept-Ranges` は `bytes`。
  - `Cache-Control` は `private, max-age=3600`。
- 事後条件（失敗）: なし

### フロー

1. ユーザーが `/media/` に名前を続けて開く。フォルダで区切られた名前は、区切りを含んだまま続ける。空白や `#` は、URL ではエンコードして開く。
2. ブラウザは、状態 200 でその中身を受け取る。
3. ブラウザは、`Content-Type` を受け取る。置いたときに付いていればそれ、無ければ拡張子で決めたもの。
4. ブラウザは、`Accept-Ranges: bytes` と `Cache-Control: private, max-age=3600` を受け取る。

## UC-MEDIA-03 範囲を渡す

- ID: UC-MEDIA-03
- 名前: 範囲を渡す
- 主アクター: ユーザー
- 事前条件: その名前の画像か動画が置いてある。
- 事後条件（成功）:
  - 状態は 206。本文はその範囲だけ。
  - `bytes=開始-終了` では、両端を含むバイトが返り、`Content-Range` は `bytes 開始-終了/全体の長さ`。例は、長さ 1024 の `bytes=0-99` に対し `bytes 0-99/1024`、本文 100 バイト。
  - `bytes=-長さ` では、末尾からその長さが返る。例は、長さ 1024 の `bytes=-50` に対し `bytes 974-1023/1024`、本文 50 バイト。
- 事後条件（失敗）: なし

### フロー

1. ユーザーが、同じ URL に `Range: bytes=開始-終了` を付けて取る。
   - 1a. ユーザーが `Range: bytes=-長さ` を付けて取る。
     1. ブラウザは、状態 206 で末尾からその長さを受け取る。
2. ブラウザは、状態 206 で両端を含むバイトを受け取る。

## UC-MEDIA-04 開けない配信を拒む

- ID: UC-MEDIA-04
- 名前: 開けない配信を拒む
- 主アクター: ユーザー
- 事前条件: なし
- 事後条件（成功）: 状態は 404。本文は「見つかりません。」
- 事後条件（失敗）: なし

### フロー

1. ユーザーが `/media/` の下を開く。パスが空、`..` を含む、`\` を含む、先頭が `/`、空の区切りを含む、壊れた `%`、画像でも動画でもない拡張子、または置いていない名前である。
2. ブラウザは、状態 404 と本文「見つかりません。」を受け取る。画像でも動画でもない拡張子は、中身が置いてあっても同じ。

## UC-MEDIA-05 無い場所を拒む

- ID: UC-MEDIA-05
- 名前: 無い場所を拒む
- 主アクター: ユーザー
- 事前条件: なし
- 事後条件（成功）: 状態は 404。本文は「見つかりません。」
- 事後条件（失敗）: なし

### フロー

1. ユーザーが、`/`、`/api/media`、`/media/`、タブの印、以外の場所を開く。
2. ブラウザは、状態 404 と本文「見つかりません。」を受け取る。

## UC-MEDIA-06 HEIC と HEIF を渡す

- ID: UC-MEDIA-06
- 名前: HEIC と HEIF を渡す
- 主アクター: ユーザー
- 事前条件: HEIC または HEIF の画像が置いてある。
- 関連: `Content-Type` は UC-MEDIA-01。
- 事後条件（成功）: 中身は渡っている。Windows のブラウザでは、絵として出ないことが多い。
- 事後条件（失敗）: なし

### フロー

1. ユーザーが、ギャラリーのタイルでその画像を見る。または UC-MEDIA-01 で中身を取る。
2. ブラウザは中身を受け取る。
