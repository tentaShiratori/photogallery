# UC-04 フォルダをアップロードする

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-04
- 名前: フォルダをアップロードする
- 主アクター: スクリプト
- 事前条件: なし
- 関連: R-MEDIA-04 は対象の拡張子。R-MEDIA-01 は名前の形。R-MEDIA-03 は撮影日時の決め方。
- 事後条件（成功）:
  - 対象が 1 件以上のとき、コンソールに「本番の photogallery-media へ N 件」が出ている。上がった件ごとに `uploaded 手元の名前 -> 付けた名前 (バイト数 bytes)` が出ている。付けた名前は本体。サムネイルを書いてから本体が置かれている。この行の並びは、フォルダの並びどおりとは限らない。手元の画像と動画は残っている。
  - 対象が 0 件のとき、「アップロード対象の画像・動画はフォルダ直下にありませんでした。」が出ている。
  - 件数が 1 件以上のとき、送り先の行のあとで `yes` 以外を入力すると、「キャンセルしました。何も上げませんでした。」が出て、置き場には何も置かれていない。
  - ローカルのとき、送り先の行は「ローカルの photogallery-media へ N 件」である。確認は待たない。上がった件の行と置き方は本番と同じである。
- 事後条件（失敗）:
  - フォルダを渡さないときは、「使い方: pnpm upload:prd <フォルダ>」が出て、失敗している。ローカルのときは「使い方: pnpm upload:local <フォルダ>」である。
  - 指定したパスがフォルダでないときは、「フォルダではありません: 」のあとにそのパスが出て、失敗している。
  - `yes` のあと、必要な設定が無いときは、未設定の項目名のあとに「が未設定です。.env.example を見て .env を作ってください。」が出て、失敗している。置き場には何も置かれていない。
  - ローカルで、普段の開発用サーバーが動いていて置き場へ書けないときは、「`pnpm dev` を止めてから実行して」が出て、失敗している。置き場には何も置かれていない。
  - 件数を出したあと、名前を決めている途中で失敗したときは、どの画像も動画も上がっていない。
  - 上げている途中で一部が失敗したときは、`failed 手元の名前: 理由` が出て、終わったあと「N 件失敗しました。」で失敗している。失敗しなかったものは置かれている。

### フロー

1. スクリプトが `pnpm upload:prd <フォルダ>` で起動する。先頭の `--` は読み飛ばす。
   - 1a. ローカルである。
     1. スクリプトが `pnpm upload:local <フォルダ>` で起動する。先頭の `--` は読み飛ばす。
     - 1a-e. フォルダを渡さない。
       1. スクリプトは「使い方: pnpm upload:local <フォルダ>」を出して失敗する。
     - 1a-f. 指定したパスがフォルダでない。
       1. スクリプトは「フォルダではありません: 」のあとにそのパスを出して失敗する。
     2. スクリプトは R-MEDIA-04 で対象を数える。
     - 1a-a. 対象が 0 件である。
       1. スクリプトは「アップロード対象の画像・動画はフォルダ直下にありませんでした。」を出す。
     3. スクリプトは「ローカルの photogallery-media へ N 件」を出す。
     4. スクリプトは、R-MEDIA-03 と R-MEDIA-01 で各対象の名前を決める。
     - 1a-g. 名前を決めている途中で失敗する。
       1. スクリプトは、どれも上げずに失敗する。
     5. スクリプトは、サムネイルを書いてから本体を書く。1 件ごとに `uploaded 手元の名前 -> 付けた名前 (バイト数 bytes)` を出す。付けた名前は本体。
     - 1a-h. 普段の開発用サーバーが動いていて置き場へ書けない。
       1. スクリプトは「`pnpm dev` を止めてから実行して」を出して失敗する。どれも上げない。
     - 1a-i. 上げている途中で一部が失敗する。
       1. スクリプトは `failed 手元の名前: 理由` を出し、残りの対象を続ける。
       2. スクリプトは、終わったあと「N 件失敗しました。」を出して失敗する。
   - 1e. フォルダを渡さない。
     1. スクリプトは「使い方: pnpm upload:prd <フォルダ>」を出して失敗する。
   - 1f. 指定したパスがフォルダでない。
     1. スクリプトは「フォルダではありません: 」のあとにそのパスを出して失敗する。
2. スクリプトは R-MEDIA-04 で対象を数える。
   - 2a. 対象が 0 件である。
     1. スクリプトは「アップロード対象の画像・動画はフォルダ直下にありませんでした。」を出す。
3. スクリプトは「本番の photogallery-media へ N 件」を出す。
4. スクリプトは、R-MEDIA-03 と R-MEDIA-01 で各対象の名前を決める。
   - 4e. 名前を決めている途中で失敗する。
     1. スクリプトは、どれも上げずに失敗する。
5. スクリプトは「本番へ上げます。yes と入力してください: 」を出して確認を待つ。
   - 5a. 入力が `yes` でない。
     1. スクリプトは「キャンセルしました。何も上げませんでした。」を出し、どれも上げない。
   - 5e. `yes` のあと、必要な設定が無い。
     1. スクリプトは、未設定の項目名のあとに「が未設定です。.env.example を見て .env を作ってください。」を出して失敗する。
6. スクリプトは、サムネイルを書いてから本体を書く。1 件ごとに `uploaded 手元の名前 -> 付けた名前 (バイト数 bytes)` を出す。付けた名前は本体。
   - 6e. 上げている途中で一部が失敗する。
     1. スクリプトは `failed 手元の名前: 理由` を出し、残りの対象を続ける。
     2. スクリプトは、終わったあと「N 件失敗しました。」を出して失敗する。
