# ログイン表示

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-LOGIN-01 ログイン表示を出す

- ID: UC-LOGIN-01
- 名前: ログイン表示を出す
- 主アクター: ユーザー
- 事前条件: なし
- 事後条件（成功）:
  - ログインのメールが無いとき、見出しの横は「ローカルプレビュー」である。
  - メールがあるとき、見出しの横はそのメールアドレスである。`<`、`>`、`&`、`'`、`"` は文字のままである。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがギャラリーを開く。
2. ブラウザは、見出しの横にログイン表示を出す。
   - 2a. ログインのメールが無い。
     1. ブラウザは「ローカルプレビュー」を出す。
     2. 見出しの横は「ローカルプレビュー」である。
   - 2b. メールがある。
     1. ブラウザはそのメールアドレスを出す。
     2. ブラウザは、`<`、`>`、`&`、`'`、`"` を文字として出す。
     3. 見出しの横はそのメールアドレスである。`<`、`>`、`&`、`'`、`"` は文字のままである。

## UC-LOGIN-03 本番のギャラリーを開く

- ID: UC-LOGIN-03
- 名前: 本番のギャラリーを開く
- 主アクター: ユーザー
- 事前条件: 本番のギャラリーで、開いてよい Google アカウントのメールアドレスが 1 件以上決まっている。
- 関連: 届いたあとの見出しの横は UC-LOGIN-01。ローカルプレビューは UC-LOGIN-01。
- 事後条件（成功）:
  - 許可されたメールアドレスのアカウントがギャラリーに届いている。
  - ログインしてから 24 時間たつと、そのログインは切れる。
  - 本番の公開先もプレビューも、同じ許可で守られている。
- 事後条件（失敗）: ギャラリーの画面は出ていない。Cloudflare Access の画面になっている。

### フロー

1. ユーザーが本番のギャラリーを開く。
2. ブラウザは Google へ直接進む。
3. 許可されたメールアドレスのアカウントである。
   - 3e. 許可されていない。
     1. ブラウザはギャラリーの画面を出さず、Cloudflare Access の画面を出す。
     2. ギャラリーの画面は出ていない。Cloudflare Access の画面になっている。
4. ブラウザは、そのアカウントをギャラリーに届ける。
5. ブラウザは、ログインしてから 24 時間でそのログインを切る。本番の公開先もプレビューも、同じ許可で守る。
6. 許可されたアカウントがギャラリーに届いている。ログインしてから 24 時間たつと、そのログインは切れる。本番の公開先もプレビューも、同じ許可で守られている。
