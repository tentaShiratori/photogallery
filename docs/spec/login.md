# ログイン表示

用語は [GLOSSARY.md](../../GLOSSARY.md)。

## UC-LOGIN-01

- ID: UC-LOGIN-01
- 前提: ログインのメールが渡されていない。ローカルのプレビューはここにあたる。Google のログインは通らない。
- 操作: `/` を開く。
- 見えること: 見出し「フォトギャラリー」の横が「ローカルプレビュー」。ギャラリーの画面にログインのフォームは無い。
- 例外: なし

## UC-LOGIN-02

- ID: UC-LOGIN-02
- 前提: 許可された Google アカウントとして、ギャラリーのページに届いている。
- 操作: `/` を開く。
- 見えること:
  - 見出し「フォトギャラリー」の横に、そのアカウントのメールアドレスが出る。
  - メールアドレスに含まれる `<`、`>`、`&`、`'`、`"` は文字として見え、画面の部品や命令にはならない。
  - タブの文言は「フォトギャラリー」のまま。
- 例外: なし

## UC-LOGIN-03

- ID: UC-LOGIN-03
- 前提: 本番のギャラリー。開いてよい Google アカウントのメールアドレスが 1 件以上決まっている。
- 操作: 本番のギャラリーを開く。
- 見えること: 許可されたメールアドレスの Google アカウントでログインした人だけがギャラリーに届く。届いた人の見出しの横は UC-LOGIN-02。本番の公開先もプレビューも、同じ許可で守られる。
- 例外: 許可されていない人にはギャラリーの画面が出ない。Cloudflare Access の画面になる。ローカルのプレビューはこの UC の対象外で、UC-LOGIN-01。
