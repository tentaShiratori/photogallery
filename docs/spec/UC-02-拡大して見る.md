# UC-02 拡大して見る

用語は [GLOSSARY.md](../../GLOSSARY.md)。

- ID: UC-02
- 名前: 拡大して見る
- 主アクター: ユーザー
- 事前条件: ブラウザにタイルが 1 件以上出ている。
- 関連: R-GAL-05 は動画の範囲配信。
- 事後条件（成功）:
  - 選んだタイルが画像のとき、その本体が出ている。「閉じる」が出ている。
  - 選んだタイルが動画のとき、その本体が出ている。再生を始める指定が付いている。「閉じる」が出ている。
  - 拡大表示を閉じたあと、拡大表示が閉じている。
  - 閉じた直後に同じタイルを選ぶと、拡大表示がまた開く。
  - 動画だったとき、閉じたあとに再生は止まっている。
- 事後条件（失敗）: なし

### フロー

1. ユーザーがタイルを選ぶ。
2. ブラウザは拡大表示を開く。
3. ブラウザは、選んだ 1 件を出す。
   - 3a. 選んだタイルが画像である。
     1. ブラウザは、その本体を出す。
     2. ブラウザは「閉じる」を出す。
   - 3b. 選んだタイルが動画である。
     1. ブラウザは、その本体を出す。
     2. ブラウザは、再生を始める指定を付ける。
     3. ブラウザは「閉じる」を出す。
4. ユーザーが拡大表示を閉じる操作をする。
   - 4a. ユーザーが「閉じる」を選ぶ。
     1. ブラウザは拡大表示を閉じる。
   - 4b. ユーザーが Escape を押す。
     1. ブラウザは拡大表示を閉じる。
